name: research
description: 信頼できる一次情報に基づいて問いを調査し、結果を Markdown ファイルに残す。トピックの調査、ドキュメントや API の事実確認、読み込み作業の委任をユーザーが求めたときに使う。
---

調査のために**バックグラウンドエージェント**を起動し、そちらが読んでいる間も作業を続ける。起動時は新しいコンテキストウィンドウで始める。

その仕事：

1. 問いを**一次情報**（公式ドキュメント、ソースコード、仕様、提供元の API）に当たって調べる。二次的な解説で済ませない。主張は、それを所有する出所まで辿る
2. 結果を1つの Markdown ファイルに書き、主張ごとに出所を引用する
3. 保存先はリポジトリが既に使っている置き場所の慣習に合わせる。慣習が無ければ妥当な場所に置き、場所を伝える
